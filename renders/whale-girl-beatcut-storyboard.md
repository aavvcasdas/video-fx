# 鲸鱼娘 MV 卡点复刻

这是一支基于仓库现有视频的 15 秒交叉剪辑，不新编故事、不造角色，也不生成新画面：鲸鱼娘镜头与画面内文字取自 Day 0 原视频；配乐取自本地《每天每天的抖音 - 抖音_6.mp4》。镜头按音乐小节切换，音乐内容与鲸鱼娘原片旁白/字幕不做语义配对。

## 输出规格

- 15 秒，16:9 横屏，1280×720，30 fps，H.264 + AAC。
- 画面源：`42868804351-1-192.mp4`（鲸鱼娘 / Day 0）。
- 音频源：`每天每天的抖音 - 抖音_6.mp4`，从约 0.34 秒处取 15 秒。
- 音频包络自相关显示约 0.38 秒的短脉冲（按双倍拍约 158 BPM，也可按半拍感觉理解为约 79 BPM）。每四个短脉冲约 1.519 秒，作为一组场景切点；最后一段在 15 秒处截断。
- 每小节重映射到原片的一个约 1.519 秒镜头片段；每两小节换一次调色/图像处理风格。切点辅以两帧青白闪光和轻微推镜。

## 重渲染

在仓库根目录创建虚拟环境并安装 `requirements-video.txt`，再运行：

```bash
python scripts/render_whale_girl_beatcut.py
```

脚本输出 `renders/whale-girl-beatcut.mp4`，输入文件名与本仓库素材一致。脚本只读取已有视频帧与音轨，并进行剪辑、调色、编码。
