# 字幕时间轴对齐报告

> 由 `tools/merge_timings.py` 生成。**文本**来自老模块里人工写的歌词表，
> **时间**来自参考片逐帧 OCR 实测的字幕出现/消失时刻（`src/timings/ocr/*.json`）。

>
> 三种合成方式（每节的标题里注明）：
> 1. `ocr-timed + curated-lyrics`：OCR 命中足够多，逐行取实测时间，
>    未命中的行按人工时间底稿做分段线性映射；
> 2. `legacy-handwritten + OCR 整体平移`：OCR 里基本没有歌词（终端 UI / 水印 / 长句叠显），
>    用人工时间表，但整体按 OCR 校正一个平移量；
> 3. `legacy-handwritten (未用 OCR 校验)`：没有参考片，只能用人工时间表。

> 时间单位：秒；`相似度` 是该行与 OCR 原始文本的字符相似度（0 表示没匹配上）。
