# 《月光邮局》15 秒像素 RPG 样片分镜

参考对象：`每天每天的抖音 - 抖音_2.mp4` 的像素叙事语法。下面的角色、情节和字幕均为原创，不复用参考片歌词或画面。

| 时间 | 镜头与动作 | 字幕 / 屏幕文字 |
|---|---|---|
| 0.0–2.7 秒 | 夜色城市建立；屋顶邮局、月亮和小邮差出现，任务卡弹出。 | `月光邮局` / `一封迟到的信` |
| 2.7–5.25 秒 | 星星落在屋顶，小邮差接住微光，任务进度启动。 | 今晚，替一颗星星送信。 |
| 5.25–8.2 秒 | 镜头横移，邮差穿过有灯火的屋顶，城市窗口随路径展开。 | 越过沉睡的屋顶，沿着微光前行。 |
| 8.2–11.2 秒 | 邮差抵达天空信箱，把星光沿弧线投递进去，信箱亮起。 | 把想念，寄给还没到来的清晨。 |
| 11.2–13.25 秒 | 天色转暖，街灯熄灭，任务进度填满。 | 愿你明天醒来，仍有光。 |
| 13.25–15.0 秒 | 任务完成卡收尾，邮差与信箱留在晨光里。 | `任务完成` / `明天见 · 小邮差` |

## 渲染规格

- 1280×720、30 fps、15 秒；逻辑画布 320×180，最近邻放大 4 倍。
- H.264 / yuv420p，静音；未指定音轨，因此不使用参考片中的音乐。
- 可执行 `python scripts/render_pixel_rpg.py` 重渲染；依赖见 `requirements-video.txt`。
